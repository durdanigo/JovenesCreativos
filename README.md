# Café Librería "Raccoon cafe" - Sitio Web Sencillo

Este proyecto consiste en una página web estática diseñada para un café librería, utilizando una paleta de colores pasteles cálidos que transmiten tranquilidad y comodidad, ideal para la lectura y el descanso.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio web y metadatos optimizados.
* **CSS3:** Estilos visuales, sistema de variables (`:root`), Grid Layout y diseño adaptable (Responsive Design).

## 📂 Estructura de Archivos

* `index.html`: Contiene el código fuente en HTML, incluyendo los metadatos necesarios (descripción, palabras clave, autor y viewport).
* `style.css`: Contiene la hoja de estilos, paleta de colores pasteles y media queries para adaptabilidad en diferentes dispositivos.

## 🎨 Paleta de Colores Pasteles

* **Fondo general:** Crema suave (`#FDFBF7`)
* **Encabezado y pie de página:** Beige cálido (`#E3D5CA`)
* **Bordes y acentos secundarios:** Tono arena (`#D5BDAF`)
* **Tarjetas de contenido:** Marfil suave (`#F5EBE0`)
* **Texto principal:** Marrón grisáceo (`#5C5247`)

## 📱 Adaptabilidad (Responsive Design)

El diseño utiliza **CSS Grid** con la propiedad `repeat(auto-fit, minmax(280px, 1fr))` para que las tarjetas de contenido se organicen automáticamente según el ancho de la pantalla, adaptándose perfectamente a computadoras, tabletas y teléfonos móviles.
