Guía de Comandos Básicos de Git

Domina el control de versiones de tus proyectos paso a paso.

⚙️ Configuración Inicial

Establece tus datos de usuario para los commits:

git config --global user.name "Tu Nombre" git config --global user.email tu@correo.com

🚀 Iniciando un Repositorio

Prepara y clona repositorios de trabajo:

  • git init: Inicializa un repositorio local en la carpeta.
  • git clone [url]: Clona un repositorio remoto existente.

📦 Guardando Cambios

Añade y confirma los cambios realizados:

  • git add .: Añade todos los archivos al área de preparación.
  • git commit -m "mensaje": Guarda los cambios en el historial con una descripción.

🌐 Repositorios Remotos

Sube y sincroniza tu trabajo con la nube:

  • git push origin master: Sube los commits al repositorio remoto.
  • git remote -v: Muestra la lista de repositorios remotos vinculados.
